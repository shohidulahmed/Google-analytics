Learning Analytics

Google Analytics allows website owners to understand how people interact with their websites.

What is GA4?

GA4 is Google's modern analytics platform. It uses an event-based measurement model, meaning that interactions such as clicks, page views and purchases can be recorded as events.

What is Google Tag Manager?

Google Tag Manager allows marketers and developers to manage tracking tags without having to modify website code every time a new tracking requirement is introduced.

Why are events useful?

Events allow you to measure specific interactions on a website. Examples include button clicks, form submissions, downloads and purchases.

Practising with GTM

A good way to learn GTM is to create different website interactions and then attempt to capture each interaction using triggers and variables.

Try scrolling through this article and compare what you see in Google Analytics with the events generated by Google Tag Manager.

More Practice

Continue experimenting with different buttons, links, forms and other website elements. Try creating your own custom events and parameters.

Analytics becomes much easier to understand when you can see the relationship between the website interaction, the GTM trigger, the tag and the resulting GA4 event.

This practice site is designed to give you a safe place to experiment without worrying about breaking a real website.
